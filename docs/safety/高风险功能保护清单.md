# 高风险功能保护清单

## 目的

本清单用于后续维护开发时判断哪些功能必须加保护。凡是可能影响真实微信小店账号、商品、订单、发货、财务或凭据的功能，都不能按普通按钮处理。

## 风险等级定义

| 等级 | 含义 | 开发要求 |
|---|---|---|
| 高 | 可能改变真实店铺、商品、订单、发货、凭据或资金相关数据 | 必须有二次确认、操作预览、日志记录，优先支持测试模式 |
| 中 | 主要影响本地业务数据、缓存、任务记录或导出内容 | 至少需要确认、错误提示和可追溯记录 |
| 低 | 只读查看、页面导航、普通本地设置 | 保持基础错误提示即可 |

## 高风险功能

| 功能 | 入口 / IPC | 风险 | 必须保护 |
|---|---|---|---|
| 批量下架商品 | `batch-delist-products` | 可能让真实店铺商品下架 | 目标店铺、商品数量、商品清单预览；二次确认；失败明细 |
| 发布云商品到店铺草稿 | `publish-cloud-product-to-shop-draft` | 可能向真实店铺生成商品草稿 | 显示目标店铺、商品来源、草稿数量；二次确认；操作日志 |
| 批量发布商品任务 | `enqueue-cloud-product-publish` / `enqueue-cloud-product-publish-batch` | 可能批量影响真实店铺商品 | 队列预览、限速、暂停、失败重试策略、任务日志 |
| 补发订单提交 | `submit-reship-order` | 可能触发真实补发/发货类操作 | 显示订单号、快递公司、快递单号；不可逆提示；二次确认 |
| 保存 OpenAPI 凭据 | `save-shop-open-api-credentials` | 涉及接口凭据和订单能力 | 不写日志、不明文展示、不上传；保存前说明用途 |
| 删除店铺记录 | `remove-shop` | 可能影响本地店铺管理和登录态 | 确认店铺名/ID；不得删除用户数据目录；可恢复说明 |
| 删除云商品 | `delete-cloud-products` | 删除本地云商品库数据 | 删除前显示数量和名称；建议先导出或可恢复 |
| 删除成本商品 | `delete-product` | 影响本地成本核算 | 二次确认；提示影响财务统计 |
| 删除任务记录 | `delete-task-records` | 影响任务追踪和问题排查 | 二次确认；批量删除前显示数量 |
| 保存财务/成本配置 | `save-finance-config`、`apply-cost-sku-bindings` | 影响利润、成本统计结果 | 修改前后差异展示；可回滚记录 |

## 中风险功能

| 功能 | 入口 / IPC | 风险 | 建议保护 |
|---|---|---|---|
| 同步订单 | `sync-orders` | 读取真实订单数据，可能产生接口频率压力 | 限速、失败提示、同步范围说明 |
| 同步商品 | `sync-products` | 读取真实商品数据 | 限速、同步范围说明 |
| 刷新数据看板 | `refresh-shop-data-modules`、`refresh-data-overview-shops` | 访问微信官方数据接口 | 队列状态、失败重试、缓存说明 |
| 广告数据刷新 | `refresh-ad-products` | 读取广告/余额/推广数据 | 只读说明、失败提示 |
| 导出订单/财务/商品 | `export-orders`、`export-finance-rows`、`export-cloud-products` | 导出文件可能含业务敏感数据 | 文件位置确认；不自动上传；导出后提示敏感 |
| 店铺批量登录/重登 | `add-multiple-shops`、`relogin-shop` | 影响登录态和浏览器 session | 显示目标店铺；失败后不清空旧数据 |

## 禁止默认恢复的功能

未接入公司自有接口前，以下功能必须保持禁用或阻断：

- 旧授权服务器：`apit.dajiaying.xyz`
- 旧 AI 服务：`ai.t8star.cn`
- 旧快递提号服务：`jk.dianxiaolong.net`

## 开发红线

1. 不删除旧用户数据目录：`C:\Users\Admin\AppData\Roaming\wechat-shop-automation`。
2. 不把 Cookie、token、secret、OpenAPI 凭据写入日志、文档或 GitHub。
3. 不直接上传运行产物、备份包、日志、截图和用户数据。
4. 不在未确认测试店铺前触发真实发布、发货、补发、批量下架。
5. 不直接大规模修改 `app/dist/assets/*.js`，前端应逐步重建源码。

## 后续实现建议

高风险功能统一增加一个操作保护层：

- 操作前：生成预览数据。
- 操作中：记录任务 ID、目标店铺、数量、开始/结束时间。
- 操作后：记录成功/失败明细。
- 失败时：明确哪些已执行、哪些未执行、是否可重试。
