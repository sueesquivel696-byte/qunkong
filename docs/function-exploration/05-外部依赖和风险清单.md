## 允许依赖

这些是项目文档允许保留的微信官方业务域名：

| 域名 | 用途 |
|---|---|
| `store.weixin.qq.com` | 微信小店后台、店铺/商品/订单/数据看板 |

| `res.wx.qq.com` | 微信资源文件 |

## 当前 URL 扫描结论

已通过脚本验证：

```powershell
node scripts/check-blocked-domains.js
```

结果：未发现旧第三方域名作为实时调用 URL 出现在 `app/electron` 中。

旧域名可能仍出现在 blocklist、文档或错误提示中，这是预期现象。

## 敏感数据点

| 类型 | 相关功能 | 相关文件 |
|---|---|---|
| Cookie/session | 店铺登录态、浏览器分区、恢复登录态 | `sessionService.js`、`shopBrowserManager.js`、`shopSessionRuntimeService.js` |
| OpenAPI 凭据 | 订单同步 | `credentialStore.js`、`officialApiClient.js`、`orderHandlers.js` |
| 店铺数据 | 店铺列表、分组、本地缓存 | `shopStore.js`、`shopGroupStore.js`、`syncStore.js` |
| 订单数据 | 订单缓存、导出、补发 | `orders/*` |
| 商品数据 | 商品缓存、云商品库、发布任务 | `products/*` |
| 财务数据 | 成本、财务统计、导出 | `finance/*`、`productCost*` |

## 高风险操作清单

| 操作 | 风险 | 建议保护 |
|---|---|---|
| `batch-delist-products` | 批量下架真实商品 | 二次确认、预览清单、测试店铺限制 |
| `publish-cloud-product-to-shop-draft` | 向真实店铺生成商品草稿 | 显示目标店铺、商品数量、失败回滚说明 |
| `enqueue-cloud-product-publish-batch` | 批量发布任务 | 限速、队列暂停、逐项日志 |
| `submit-reship-order` | 补发/发货类真实操作 | 明确订单号、快递单号、不可逆提示 |
| `save-shop-open-api-credentials` | 保存接口凭据 | 不写入日志、不上传、不明文展示 |
| `remove-shop` | 删除本地店铺记录 | 二次确认，不能删除用户数据目录 |
| `delete-cloud-products` / `delete-task-records` / `delete-product` | 删除本地业务数据 | 操作前备份或可恢复记录 |

## 不应上传到 GitHub

- 用户数据目录和备份。
- Cookie/session/token/secret/credential 文件。
- 日志和截图。
- 运行产物、exe、dll、pak、bin、dat、zip。
- `local-noauth-build`、`tools`、`node_modules`、`runtime`、`app/dist`。

## 后续接入公司接口的要求

若恢复 AI 作图/文案或快递补发提号功能，必须满足：

1. API 域名归公司控制，或合同明确可用。
2. API Key 不写死在代码里。
3. 配置不能进入公开文档或日志。
4. 更新 `scripts/check-blocked-domains.js`。
5. 更新 README / PROJECT_SPEC / 安全文档。
