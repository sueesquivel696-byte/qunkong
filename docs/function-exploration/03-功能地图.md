# 03-功能地图

## 说明

当前前端是 `app/dist/assets` 下的 Vue 打包产物。以下功能地图来自 bundle 文件名、preload 暴露 API、IPC 通道和后端服务交叉推断，后续如要重建前端，应逐步建立新的 `src/` 和 `.vue` 页面。

## 页面 / 模块清单

| 页面 bundle | 主要功能 | 后端线索 | 风险等级 |
|---|---|---|---|
| `ShopList-*.js` | 店铺列表、添加店铺、批量店铺、重登、检测登录态、店铺分组 | `shopHandlers.js`、`shopGroupHandlers.js`、`shopManager.js` | 中：涉及登录态和店铺会话 |
| `DataOverview-*.js` | 店铺数据概览、缓存健康、刷新模块、差评处理状态 | `dataHandlers.js`、`syncManager.js`、`services/shopData` | 中：刷新会访问微信官方数据接口 |
| `OrderManagement-*.js` | 订单缓存、订单同步、导出订单、OpenAPI 凭据 | `orderHandlers.js`、`services/orders` | 高：涉及订单数据和凭据 |
| `ReshipOrder-*.js` | 补发订单查询、快递配置、补发提交、补发记录 | `reshipOrderService.js`、`reshipExpressNumberService.js` | 高：可能触发真实补发/发货类操作 |
| `ProductManagement-*.js` | 商品缓存、同步商品、打开商品编辑、批量下架 | `productHandlers.js`、`productManagementService.js` | 高：可能修改真实商品 |
| `CloudProductLibrary-*.js` | 云商品库、编辑草稿、删除、审核、导入导出 | `cloudProductLibraryService.js`、`cloudProductRepository.js` | 中/高：本地库操作，发布前风险较低 |
| `CloudPublishTasks-*.js` | 云商品发布任务、批量发布、任务停止/重试/删除 | `cloudProductPublishService.js`、`tasks` | 高：可能发布到真实店铺草稿或队列 |
| `ProductCostManagement-*.js` | 成本商品、SKU 成本绑定、共享成本更新、删除成本商品 | `productCostHandlers.js`、`financeHandlers.js` | 中：影响本地成本核算 |
| `FinanceManagement-*.js` | 财务统计、配置、SKU 成本绑定、导出 | `financeHandlers.js`、`services/finance` | 中：涉及财务数据和导出 |
| `AdPromotionManagement-*.js` | 广告商品/推广数据、广告详情刷新 | `adProductHandlers.js`、`adProducts`、`adSessionService.js` | 中：读取广告/余额数据 |
| `DataCompass-*.js` | 数据罗盘同步和缓存 | `compassHandlers.js`、`compassService.js` | 中：访问数据分析接口 |
| `FlashSaleManager-*.js` | 限时抢购/秒杀类任务数据 | `shopData/modules/snapUp.js` | 中/高：若后续接入写操作需保护 |
| `MaterialCenter-*.js` | 素材中心、目录选择、图片复制/导出 | `materialAssetLibraryService.js`、product split 相关服务 | 低/中：主要本地文件操作 |

## 高风险功能入口

以下入口后续需要二次确认、测试模式或操作预览：

- `batch-delist-products`：批量下架商品。
- `publish-cloud-product-to-shop-draft`：发布云商品到店铺草稿。
- `enqueue-cloud-product-publish` / `enqueue-cloud-product-publish-batch`：加入发布队列。
- `submit-reship-order`：提交补发订单。
- `save-shop-open-api-credentials`：保存店铺 OpenAPI 凭据。
- `remove-shop` / `delete-shop-group` / `delete-cloud-products` / `delete-task-records` / `delete-product`：删除类操作。

## 证据

- 前端 bundle：`app/dist/assets/*Management*.js`、`ShopList-*.js`、`Cloud*.js`。
- API 暴露：`app/electron/preload.js`。
- IPC 注册：`app/electron/ipc/*.js`。
- 后端服务：`app/electron/services/**`。
