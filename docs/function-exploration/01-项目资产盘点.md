# 01-项目资产盘点

## 结论

当前主维护工程是：`E:\桌面\新建文件夹\wechat-shop-automation-rebuild`。

当前可运行本地无授权版是：`E:\桌面\新建文件夹\local-noauth-build\微信小店多店铺群控.exe`。

恢复参考目录是：`E:\桌面\新建文件夹\recovered-source` 和 `E:\桌面\新建文件夹\app_asar_unpacked`。

备份和本机数据不能作为开发入口，也不能上传到 GitHub。

## 顶层资产分类

| 路径 | 类型 | 用途 | 维护建议 |
|---|---|---|---|
| `wechat-shop-automation-rebuild` | 主维护工程 | Electron 主进程、业务服务、项目文档、脚本 | 后续开发优先改这里 |
| `local-noauth-build` | 当前运行产物 | 当前可双击运行的软件目录，包含 exe 和 Electron 运行时 | 不直接开发，不上传 |
| `recovered-source` | 恢复源码参考 | 早期从打包产物恢复的源码和恢复说明 | 只读参考 |
| `app_asar_unpacked` | 原始 asar 解包参考 | 原始运行包解包后的 `dist/electron/shared` | 只读对照 |
| `final-backups` | 备份 | 历史 zip 备份 | 不改、不上传 |
| `tools` | 本机工具 | 便携 Node.js、MinGit | 不上传 |
| `wechat-shop-automation-userData-backup-*.zip` | 用户数据备份 | 可能包含店铺登录态、缓存、任务记录 | 高敏感，不上传 |

## 当前主工程结构

| 路径 | 说明 |
|---|---|
| `app/electron` | 目前最可维护的主进程、IPC、controller、service 代码 |
| `app/shared` | 公共静态数据，例如快递公司、商品媒体字段标签 |
| `app/dist` | 前端 Vue 打包产物，不是原始 `.vue` 源码 |
| `scripts` | 本地启动、阻断域名检查脚本 |
| `reports` | 验证/安全扫描报告，截图默认不上传 |
| `runtime` | 运行/打包产物，默认不上传 |
| `node_modules` | 依赖安装产物，默认不上传 |
