# 04-页面到后端链路

## 总体链路

```text
前端打包页面 app/dist/assets
  -> preload 暴露 window.electronAPI
  -> ipcMain handler: app/electron/ipc/*.js
  -> controller: app/electron/controllers/*.js
  -> service/repository: app/electron/services/**
  -> 本地 JSON 文件 / Electron session / 微信官方接口
```

| 模块 | IPC 文件 | 主要通道 |

| 商品 | `productHandlers.js` | `sync-products`、`batch-delist-products`、`save-product-to-cloud-library`、`enqueue-cloud-product-publish` |

## 真实写操作风险

- 商品：批量下架、打开编辑页、发布到草稿、发布队列。
- 订单：保存 OpenAPI 凭据、同步订单、补发提交。
- 店铺：添加/删除店铺、重登、批量登录。
- 财务/成本：保存成本配置、绑定 SKU、删除本地成本商品。
- 任务：停止、重试、删除任务记录。

后续实现这些功能时，应加操作确认、测试模式、操作预览、失败日志和回滚/补偿说明。
